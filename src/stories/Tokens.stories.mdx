## 🏗️ Estructura de Tokens

Los tokens están organizados en tres niveles jerárquicos:

### 1. **Primitives** - Tokens Base

Valores fundamentales sin contexto de uso específico.

<div style={{
  backgroundColor: '#f5f5f5',
  padding: '1rem',
  borderRadius: '8px',
  fontFamily: 'monospace',
  fontSize: '0.9rem',
  marginBottom: '1rem'
}}>
  <div><strong>Colors:</strong> Paleta base (#00686f, #99cc00, grises, status)</div>
  <div><strong>Typography:</strong> Fuentes, tamaños, weights</div>
  <div><strong>Spacing:</strong> Escala de espaciado (8px, 16px, 24px...)</div>
  <div><strong>Radius:</strong> Border radius (4px, 8px, 12px, 24px)</div>
  <div><strong>Motion:</strong> Duraciones y easings de animaciones</div>
</div>

### 2. **Semantic** - Tokens Semánticos

Tokens con significado contextual (light + dark mode).

<div style={{
  backgroundColor: '#f5f5f5',
  padding: '1rem',
  borderRadius: '8px',
  fontFamily: 'monospace',
  fontSize: '0.9rem',
  marginBottom: '1rem'
}}>
  <div><strong>Colors:</strong> primary, secondary, error, warning, info, success</div>
  <div><strong>Light Mode:</strong> Colores optimizados para fondo claro</div>
  <div><strong>Dark Mode:</strong> Colores optimizados para fondo oscuro</div>
</div>

### 3. **Component** - Tokens de Componentes

Tokens específicos para cada componente (light + dark mode).

<div style={{
  backgroundColor: '#f5f5f5',
  padding: '1rem',
  borderRadius: '8px',
  fontFamily: 'monospace',
  fontSize: '0.9rem',
  marginBottom: '1rem'
}}>
  <div><strong>Alert:</strong> Tokens para variantes error, warning, info, success</div>
  <div><strong>Button:</strong> Border radius, heights, padding</div>
  <div><strong>Inputs:</strong> Borders, fill colors, sizing</div>
  <div><strong>Surfaces:</strong> Paper elevations, cards, dialogs</div>
</div>

## ⚡ Comandos Rápidos

```bash
# Regenerar tokens
npm run tokens:build

# Watch mode
npm run tokens:watch

# Sincronizar desde Figma
npm run tokens:sync:pull

# Previsualizar cambios
npm run tokens:sync:dry-run
```

### Proceso de Sincronización

1. **Diseñador** actualiza tokens en Figma
2. Tokens Studio hace **push a GitHub**
3. Desarrollador hace **pull** y ejecuta `npm run tokens:build`
4. Los tokens se **regeneran** en múltiples formatos
5. Componentes se **actualizan automáticamente**

## 📝 Ejemplos de Uso

### TypeScript/React

```typescript
import {
  SemanticColorLightPrimaryMain,
  ComponentButtonBorderRadius,
  PrimitivesSpacing2
} from '@mgomez-ext/mrs-ui/tokens';

const MyButton = () => (
  <button
    style={{
      backgroundColor: SemanticColorLightPrimaryMain,
      borderRadius: ComponentButtonBorderRadius,
      padding: PrimitivesSpacing2,
    }}
  >
    Click me
  </button>
);
```

### CSS

```css
@import '@mgomez-ext/mrs-ui/tokens/generated/css/tokens.css';

.my-button {
  background-color: var(--mrs-semantic-color-light-primary-main);
  border-radius: var(--mrs-component-button-border-radius);
  padding: var(--mrs-primitives-spacing-2);
}
```

### SCSS

```scss
@import '@mgomez-ext/mrs-ui/tokens/generated/scss/tokens';

.my-button {
  background-color: $mrs-semantic-color-light-primary-main;
  border-radius: $mrs-component-button-border-radius;
  padding: $mrs-primitives-spacing-2;
}
```
